# Pasta Public

Esta pasta contém arquivos estáticos que serão servidos diretamente.

## Logo no Header

Para adicionar uma imagem de logo no **header fixo no topo da página**:

1. Adicione sua imagem de logo nesta pasta com o nome `logo.png` (ou `logo.jpg`, `logo.svg`, etc.)
2. Formatos suportados: PNG, JPG, SVG, WEBP
3. Tamanho recomendado: 
   - Largura: 200-400 pixels (será ajustada automaticamente)
   - Altura: 64 pixels (altura do header)
   - Proporção: horizontal/retangular funciona melhor

A imagem será exibida automaticamente no **header fixo no topo** quando disponível. O header fica sempre visível, mesmo ao rolar a página.

**Nota:** Se a imagem não for encontrada, será exibido o texto "Agente Comercial" como fallback.
